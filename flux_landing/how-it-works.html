The Engine Protocol.

Five precise stages. From zero to submitted application. Built on Mem0, pgvector RAG, browser-use, and Twilio — each step automated so you don't have to be.

1

Ingest, Vectorize & Remember

Upload your resume (PDF or DOCX) or paste your GitHub profile URL. FLUX's ingestion pipeline fires on two tracks simultaneously: OpenAI embedding models convert your skills and achievements into 3072-dimensional vectors stored in Supabase pgvector, while Mem0 stateful memory stores your preferences, target roles, and career history across every future session. One upload. Permanent, persistent context.

Supabase pgvector OpenAI Embeddings Mem0 Stateful Memory GitHub Ingestion
2

Semantic Match Discovery

The Orchestrator agent runs a continuous, automated crawl of Greenhouse, Lever, and LinkedIn ATS boards via the Tavily Job Crawler. Rather than naive keyword matching, FLUX deploys Reciprocal Rank Fusion (RRF) Hybrid Search — querying job description vectors against your pgvector profile to surface only high-fidelity matches above your configured threshold.

Tavily Job Crawler RRF Hybrid Search LinkedIn Fast Scraper Semantic Gap Analysis
3

Browser Inception & Auto-Fill

For every high-scoring match, the browser launcher boots a headless Chromium session and mounts your live Chrome user data directory — so it's already logged into LinkedIn, Naukri, and Greenhouse. The Python browser-use agent uses LLM vision to parse dynamic form fields, writes tailored essay responses using your Mem0 context, uploads your resume, and submits. Exactly like a real human. Every time.

browser-use Agent Headless Chromium LLM Vision Form Parsing On-the-Fly Essay Solver
4

Anti-Ban Security & Resilient Recovery

Every tool execution is governed by a token-bucket rate limiter — 50 burst operations, refilling 1 token every 2 seconds — ensuring FLUX never triggers suspicious rate patterns on strict job boards. If a CAPTCHA or 2FA gate appears, the system emits a HUMAN_INTERVENTION_REQUIRED signal, fires an instant WhatsApp alert, freezes the queue, and waits. You solve it in the visible browser. Full state is preserved. Zero applications lost.

Token-Bucket Limiter Resilient Pauses Twilio WhatsApp Webhooks 15s Global Timeouts
5

Recruiter Intel & Live Feedback

The moment an application is submitted, your Career Cockpit updates. When a recruiter opens your PDF, the Twilio webhook captures the status change and triggers an ElevenLabs TTS synthesis — generating a natural voice memo briefing you on the recruiter's name, company, and action taken. Your job search doesn't just run on autopilot. It talks back to you.
