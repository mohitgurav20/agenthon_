The Full Tech Stack

Supabase pgvector RAG

Your resume is converted into 3072-dimensional semantic vectors using OpenAI embeddings, stored in Supabase pgvector. When a job drops, Reciprocal Rank Fusion (RRF) Hybrid Search instantly scores it against your profile — ranking matches with true semantic context, not just keyword overlap.

Resilient Pauses

Human-in-the-Loop safety by design. When the browser agent encounters a CAPTCHA or 2FA challenge, the pipeline emits a HUMAN_INTERVENTION_REQUIRED event — pausing instantly, firing a WhatsApp webhook alert, and resuming automatically once you solve it in the visible browser window. No lost state, ever.
