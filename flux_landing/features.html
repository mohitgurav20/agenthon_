Supabase pgvector RAG

Your resume is chunked and vectorized into 3072-dimensional embeddings via OpenAI. Every project, skill, and achievement is stored as a semantic coordinate in Supabase pgvector. When jobs drop, RRF Hybrid Search runs a simultaneous full-text + semantic scan — ranking matches in milliseconds, not keywords.

Token-Bucket Rate Limiting

Mathematically governed application pacing. A token-bucket algorithm caps all tool executions at 50 burst requests, refilling 1 token every 2 seconds. Your account is never flagged, never suspended. The system applies at full speed within safe operating thresholds.

Human-in-the-Loop Resilient Pauses

When the browser agent detects a CAPTCHA or 2FA gate, it emits a HUMAN_INTERVENTION_REQUIRED event, gracefully freezes the execution queue, and fires a WhatsApp alert with a deep link. You solve it in the open browser window. The agent resumes from exactly where it left off — full state preserved.
