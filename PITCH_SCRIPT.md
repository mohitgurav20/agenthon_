# 3-Minute Pitch Script Template

**[0:00 - 0:30] The Hook (30s)**
"The problem is [X]. Every [target audience] faces [Y]."

**[0:30 - 2:30] The Live Demo (2m)**
*Demonstrate 3 WOW moments:*
1. "Watch as our agent researches the user's specific context..." (Show CopilotKit thinking / Langfuse observability)
2. "Notice how it remembers what we discussed 3 sessions ago..." (Show Mem0/Letta persistence)
3. "Finally, it takes real action in the background..." (Show WhatsApp notification / Bland AI call)

**[2:30 - 3:00] The Close (30s)**
"Our agent does [Z]. It's fundamentally different because [W]."
